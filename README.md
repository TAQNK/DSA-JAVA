# 🎯 Problem-Solving Strategy

For every problem:

1. [ ] Understand the problem
2. [ ] Identify input/output
3. [ ] Write the brute-force approach
4. [ ] Analyze time complexity
5. [ ] Analyze space complexity
6. [ ] Find an optimized approach
7. [ ] Write pseudocode
8. [ ] Implement in Java
9. [ ] Test edge cases
10. [ ] Revisit the problem later without looking at the solution
